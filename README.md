# SiteCheck

เว็บแอปแบบ static ไฟล์เดียว สำหรับเช็คว่าทีมช่าง/ผู้รับเหมาเข้างานวันไหน เช็ควันละ 3 รอบ (09:00 / 13:00 / 17:00) แสดงเป็น calendar heatmap เก็บรูปหลักฐานได้ และ export สรุปรายเดือนเป็น PDF

## ฟีเจอร์

- บันทึกแต่ละรอบว่าทีมไหนเข้างาน (เลือกได้หลายทีม) หรือ "ไม่มีใครเข้า"
- จำนวนคนต่อทีมต่อรอบ (ไม่บังคับ)
- หมายเหตุ + แนบรูปจากกล้อง (ไม่บังคับ) — รูปย่อขนาดอัตโนมัติ
- Calendar heatmap: ช่องละวัน ไล่เข้มตามจำนวนทีมที่เข้า, ✕ = ไม่มีใครเข้า, ว่าง = ไม่ได้บันทึก
- บันทึกย้อนหลังได้ (แตะวันในปฏิทิน)
- เพิ่ม / เปลี่ยนชื่อ / ลบทีม
- รายงานรายเดือน: สถิติ, วันเข้างานแยกตามทีม, heatmap, ตารางรายวัน, ภาคผนวกรูป, ช่องเซ็นเจ้าของบ้าน–ผู้รับเหมา → กด "บันทึกเป็น PDF"
- แจ้งเตือนรอบตรวจ (ทำงานเฉพาะตอนเปิดหน้าเว็บค้างไว้)

## Deploy บน GitHub Pages

1. สร้าง repository ใหม่
2. อัปโหลด `index.html` ไว้ที่ root ของ repo
3. **Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)` → Save**
4. รอ 1–2 นาที แล้วเปิด `https://<username>.github.io/<repo>/`

บนมือถือ: เปิดลิงก์ใน Safari/Chrome → **Add to Home Screen** จะใช้งานเหมือนแอป

## การเก็บข้อมูล

- ข้อมูลและรูปทั้งหมดเก็บใน `localStorage` ของ browser บนเครื่องนั้น
- **ไม่ sync ข้ามเครื่อง** และจะหายถ้าล้างข้อมูล browser / ลบเว็บออกจากหน้าโฮม
- แนะนำ export PDF ทุกสิ้นเดือนเป็น backup
- ความจุ localStorage ประมาณ 5 MB — รูปถูกย่อเหลือ ~900px / JPEG 62% (ราว 60–120 KB ต่อรูป) จึงเก็บได้หลายสิบรูปต่อเดือน ถ้าเต็มให้ลบรูปเก่าหรือเริ่มเดือนใหม่

## Export PDF

หน้า "รายงาน" → "บันทึกเป็น PDF" จะเปิดหน้าพิมพ์ของ browser → เลือก **Save as PDF**
ปุ่ม "ซ่อนรูปหลักฐาน" ใช้ตัดภาคผนวกรูปออกถ้าต้องการไฟล์เล็ก
